# АИС для транспортной компании: описание проекта

## Название проекта

Автоматизированная информационная система (АИС) для транспортной компании.

## Цель проекта

Разработать автоматизированную систему определения объёма груза в заданной зоне склада.

## Задачи проекта

- Разработать систему определения объёма груза посредством YOLO-модели
- Провести дополнительное финальное тестирование системы
- Внедрить проект на территории заказчика

## Актуальность

Использование нейронной сети для определения объёма в заданной зоне склада позволяет решить три ключевые задачи:

**Контроль соответствия объёма груза перед погрузкой.** Приложение позволяет точно определить объём партии груза непосредственно перед помещением в транспортное средство, что обеспечивает соответствие планируемым данным и предотвращает ошибки.

**Оптимизация использования грузового пространства.** Автоматическое определение объёма помогает рационально распределить груз в кузове транспортного средства, обеспечивая максимальную загрузку и снижая риски повреждения при транспортировке.

**Повышение скорости и точности погрузочных работ.** Использование системы исключает задержки и человеческие ошибки, связанные с ручными замерами, что ускоряет процесс погрузки и повышает общую эффективность логистической цепочки.

## Проблематика проекта

Существующий процесс оценки объёма груза перед погрузкой опирается исключительно на визуальную оценку сотрудниками. Этот подход имеет ряд системных недостатков:

- **Низкая точность и субъективность.** Визуальная оценка подвержена значительным погрешностям и субъективному мнению сотрудника, что приводит к неверным данным об объёме.
- **Нерациональное использование транспорта.** Неправильно определённый объём груза приводит к неполной загрузке транспортного средства или, наоборот, к его перегрузу, что вызывает финансовые потери и нарушение логистических планов.
- **Отсутствие объективного контроля.** Процесс не оставляет зафиксированных данных для последующего аудита, что делает невозможным установление причин ошибок и приводит к спорным ситуациям между отделами логистики и клиентами.

## Предлагаемое решение

АИС использует нейросеть YOLOv8 для распознавания габаритов и типа груза в реальном времени:

- Время обработки одного груза — 10 секунд (вместо 3 минут)
- Точность распознавания — более 95%
- Бесшовная интеграция с WMS/TMS-системами через API на FastAPI
- Автоматическая фото-фиксация каждого груза с привязкой к накладной
- Готовая отчётность по объёму, расхождениям и загруженности транспорта

## Взаимодействие с заказчиком

Заказчик — ООО «ЖелДорЭкспедиция», крупнейший транспортный оператор сборных грузов в России. В рамках сотрудничества:

- Заказчик предоставляет данные для формирования обучающего материала
- Заказчик предоставляет вычислительные ресурсы для проведения обучения разработанной нейронной сети

## Этапы проведённой работы над промежуточным продуктовым результатом

- Разработан алгоритм, позволяющий рассчитать объём груза на основе данных детекции YOLOv8
- Программа протестирована и улучшена по результатам тестовых прогонов
- Добавлен удобный способ передачи данных через API на FastAPI

## Стек технологий

- **Python** — основной язык разработки алгоритмов и API
- **YOLOv8** — нейросеть для детекции объектов на изображениях
- **FastAPI** — фреймворк для создания REST API
- **OpenCV** — библиотека для обработки изображений
- **Docker** — контейнеризация для быстрого развёртывания
- **HTML + CSS** — веб-интерфейс и статический сайт проекта
- **pyTelegramBotAPI** — библиотека для создания Telegram-бота
