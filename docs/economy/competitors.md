## 1. Верхний уровень: прямые аналоги

Системы, которые также анализируют объём и габариты паллет и упаковок, часто с использованием 3D-камер или искусственного интеллекта. Являются полной заменой нашему решению.

**Зарубежные конкуренты:**

- **Cognex (3D-A1000)** — промышленное зрение для измерения габаритов коробок и паллет
- **Mettler Toledo (Cargoscan, Dimensioning)** — профессиональное оборудование для взвешивания и измерения грузов
- **SICK (LMS/PLS)** — лазерные сканеры для определения объёма и веса паллет
- **Keyence** — системы машинного зрения для контроля упаковок

**Российские конкуренты:**

- **3DControl** — российская система объёмного анализа грузов
- **Склад-Интеллект** — модули аналитики паллет (без ИИ-зрения)

## 2. Средний уровень: косвенные заменители

Решают смежные задачи. Клиент может использовать их для оценки кубатуры, хотя объём не является их основной функцией.

| Тип решения | Пример | Как измеряют объём | Почему конкурент |
|-------------|--------|-------------------|------------------|
| WMS с модулем объёма | 1С:WMS, Solvo.WMS, Lead WMS | Вручную или с интеграцией весов | «Нам хватает ручного ввода, не нужен ИИ» |
| ERP + логистика | 1С:ERP, SAP EWM | Расчётный (по номенклатуре) | Не измеряет реальный объём, но дёшево |
| Фото-фиксация (без ИИ) | Hikvision, Ivideon | Только визуальный контроль | Клиент думает: «камер хватит» |

**Слабые места косвенных заменителей:**

- Нет автоматического распознавания границ груза
- Нет ИИ-помощника

## 3. Нижний уровень: ручные методы

Самый дешёвый «конкурент» — отсутствие автоматизации. Главная угроза для продаж.

- **Кладовщик с рулеткой и блокнотом** — объём по формуле (ДxШxВ), ошибки 10–20%
- **Мобильный ТСД с ручным вводом** — ввод габаритов через интерфейс WMS
- **Оценка «на глаз»** — штабелирование без измерения, конфликты с перевозчиком
- **Только вес** — объём не учитывается, хотя для фур и контейнеров критичен

## 4. Технологические заменители

| Технология | Кто делает | Когда может стать конкурентом |
|------------|------------|-------------------------------|
| 3D-сканеры смартфонов (LiDAR) | Apple + приложения | 1–2 года |
| Дроны с RGB-D камерами | DJI | Для больших складов |
| ИИ от производителей камер | Hikvision AI, Dahua IVS | При добавлении модуля измерения |
| Бесконтактные сенсоры (mmWave) | Texas Instruments, Infineon | Пока низкая точность |

## 5. Стратегическая карта по сегментам

| Главный конкурент | Наше преимущество |
|-------------------|-------------------|
| Cognex / Mettler Toledo | Ниже цена, быстрее внедрение |
| 1С:WMS + ручной ввод | Автоматизация без ошибок, ИИ-помощник |
| Лазерные сканеры SICK / Keyence | Гибкость: работа с нестандартными формами |
| Рулетка + Excel | «Вы теряете 15% объёма фуры — вот калькулятор» |

## Вывод

Конкурентный ландшафт подтверждает уникальность нашего решения. У зарубежных аналогов высокая стоимость и длительные сроки внедрения, у российских — отсутствие ИИ-компонента. Ручные методы дёшевы, но приводят к потерям до 15% объёма транспорта. Технологические заменители пока не готовы к массовому внедрению. Ключевое преимущество АИС — сочетание низкой цены, быстрого запуска и гибкости нейросети.
