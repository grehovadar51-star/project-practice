# Юнит-экономика АИС для транспортной компании

## Исходные данные

Расчёт на один груз (единицу продукции).

| Показатель | Значение |
|------------|----------|
| Затраты на обработку одного груза | 5 руб. |
| Экономия труда (ручной замер → авто) | 17 руб. |
| Снижение рекламаций | 5 руб. |
| Логистический эффект | 4 руб. |

## Результат

| Показатель | Значение |
|------------|----------|
| Совокупный эффект на 1 груз | 26 руб. |
| Затраты на обработку | 5 руб. |
| Чистый эффект (Unit Profit) | 21 руб. |
| Маржинальность | 80,8% |
| Коэффициент Value / Затраты | 5,2x |

## Вывод

Каждый обработанный груз приносит 21 рубль чистой экономии. На каждый затраченный рубль система возвращает 5,2 рубля ценности. При объёме 20 000 грузов в месяц чистая экономия составляет 420 000 рублей, что подтверждает высокую рентабельность решения.
