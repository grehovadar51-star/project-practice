# Экономическая эффективность и ROI

## Годовые показатели

Расчёт выполнен для среднего склада транспортной компании с грузопотоком около 20 000 грузов в месяц.

При внедрении АИС каждый обработанный груз приносит 21 рубль чистой экономии. Эта цифра складывается из сокращения времени оператора (с трёх минут до десяти секунд), снижения количества рекламаций благодаря фото-фиксации и оптимальной загрузки транспорта за счёт точного знания кубатуры.

| Показатель | Значение |
|------------|----------|
| Общий грузопоток за год | 238 000 грузов |
| Чистый эффект в месяц | 420 000 руб. |
| Чистый эффект за год | 5 040 000 руб. |
| Операционные затраты за год | 1 190 000 руб. |
| Годовая прибыль | 3 808 000 руб. |
| Рентабельность | 80,8% |
| Эффект на 1 рубль затрат | 5,2x |

Затраты складываются из стоимости оборудования (камеры) и поддержки системы. При этом на каждый затраченный рубль система возвращает 5,2 рубля ценности — это высокий показатель даже для ИТ-продуктов.

## Сравнение с лазерными сканерами

Лазерные сканеры (SICK, Keyence и аналоги) — основной технологический конкурент АИС. Принципиальная разница: лазерные системы требуют покупки дорогостоящего оборудования, тогда как АИС работает на стандартных камерах с нейросетевой обработкой.

| Критерий | АИС (наше решение) | Лазерные сканеры |
|----------|---------------------|-------------------|
| Стоимость внедрения | ПО + стандартные камеры | 5–15 млн руб. |
| Срок внедрения | 2–4 недели | 3–6 месяцев |
| Затраты на 1 груз | ~5 руб. | ~15–25 руб. |
| Точность распознавания | >95% | ~90% |
| Гибкость для нестандартных форм | Высокая (ИИ) | Низкая (фиксированные шаблоны) |
| Интеграция с WMS/TMS | Нативная (API) | Требует доработки |
| Окупаемость (при 20 тыс. грузов/мес.) | < 3 месяцев | 12–24 месяца |

АИС превосходит лазерные сканеры по всем ключевым параметрам: стоимость внедрения ниже в десятки раз, срок запуска — 2–4 недели против 3–6 месяцев, затраты на один груз — 5 рублей против 15–25 рублей. При этом точность выше (95% против 90%), а гибкость ИИ позволяет работать с нестандартными формами грузов, недоступными для шаблонных лазерных систем.

## Расчёт ROI относительно лазерных сканеров

Если компания уже использует лазерные сканеры, переход на АИС даёт дополнительную выгоду.

| Показатель | Значение |
|------------|----------|
| Годовая экономия на АИС | 5 040 000 руб. |
| Оценочные затраты на лазерные сканеры (15 руб./груз × 240 000) | 3 600 000 руб. |
| Дополнительная экономия при переходе с лазерных сканеров на АИС | 2 400 000 руб./год |
| ROI перехода | Окупаемость менее 3 месяцев |

Окупаемость перехода составляет менее трёх месяцев только за счёт разницы в стоимости обработки одного груза (5 рублей против 15–25 рублей). После окупаемости система продолжает приносить прибыль.

## Вывод

При годовом грузопотоке 238 000 единиц система приносит более 3,8 млн рублей чистой прибыли с рентабельностью 80,8%. Переход с лазерных сканеров на АИС даёт дополнительную экономию 2,4 млн рублей в год. Окупаемость составляет менее трёх месяцев, что делает проект привлекательным для быстрого внедрения на складах транспортных компаний любого масштаба.
