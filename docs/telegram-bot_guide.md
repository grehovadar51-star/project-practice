# Техническое руководство: создание Telegram-бота для АИС транспортной компании

## 1. Исследование предметной области

### 1.1. Зачем транспортной компании Telegram-бот

Транспортные компании ежедневно обрабатывают сотни грузов. Основные проблемы:

- Ручной замер объёма груза занимает ~3 минуты
- Ошибки измерений достигают 10–20%
- Недозагрузка транспорта до 15%

Автоматизированная информационная система (АИС) на базе YOLOv8 решает эти проблемы. Telegram-бот выступает витриной продукта: демонстрирует возможности системы потенциальным заказчикам и партнёрам.

### 1.2. Выбор технологии для бота

Для разработки Telegram-бота были рассмотрены три популярные Python-библиотеки:

**pyTelegramBotAPI (telebot)** — самая простая в освоении библиотека с интуитивно понятным синтаксисом. Поддерживает все необходимые функции: команды, кнопки меню, Inline-кнопки, отправку фото. Идеально подходит для быстрого создания ботов и обучения.

**python-telegram-bot** — более мощная библиотека с асинхронной архитектурой. Имеет отличную документацию и большое сообщество. Требует понимания асинхронного программирования (async/await).

**Aiogram** — профессиональный фреймворк с разделением на хендлеры, мидлвари и FSM. Избыточен для простых ботов и сложен для начинающих.

Выбрана библиотека pyTelegramBotAPI (telebot) по следующим причинам:
- Минимальный порог входа — достаточно базовых знаний Python
- Интуитивно понятный синтаксис на основе декораторов
- Полный набор необходимых функций (меню, кнопки, фото, калькулятор)
- Активная поддержка и регулярные обновления

### 1.3. Архитектура взаимодействия

```
+--------------+      +---------------+      +--------------+
| Пользователь | ---> | Telegram API  | ---> |  telebot     |
|  (Telegram)  | <--- |  (облако)     | <--- |  (Python)    |
+--------------+      +---------------+      +--------------+
                                                     |
                                              +------+------+
                                              | @bot.message|
                                              |  _handler   |
                                              +-------------+
```

*Рис. 1 — Схема взаимодействия: пользователь отправляет сообщение, Telegram API передаёт его библиотеке telebot, которая вызывает соответствующий обработчик*

## 2. Пошаговая инструкция по созданию бота

### Шаг 1: Установка Python

1. Скачайте Python с официального сайта: https://python.org
2. При установке отметьте галочку "Add Python to PATH"
3. Проверьте установку:

```bash
python --version
```

### Шаг 2: Установка библиотеки

Откройте терминал (командную строку) и выполните:

```bash
pip install pyTelegramBotAPI
```

*Рис. 2 — Установка библиотеки через pip*

### Шаг 3: Регистрация бота в Telegram

1. Откройте Telegram
2. В поиске найдите @BotFather (официальный аккаунт с синей галочкой)
3. Отправьте команду `/newbot`
4. Введите имя бота (например: "АИС Транспорт")
5. Введите username бота (например: `transport_ais_bot`)
6. Сохраните токен — длинную строку вида `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**Важно:** Никому не показывайте токен! Любой, у кого есть токен, может управлять вашим ботом.

*Рис. 3 — Регистрация бота через @BotFather*

### Шаг 4: Создание файла бота

Создайте папку `src/` и файл `main.py`:

```python
import telebot
from telebot import types

TOKEN = "ваш_токен_здесь"
bot = telebot.TeleBot(TOKEN)

@bot.message_handler(commands=['start'])
def send_welcome(message):
    bot.reply_to(message, "Привет! Я бот АИС для транспортной компании.")

if __name__ == "__main__":
    print("Бот запущен!")
    bot.infinity_polling()
```

### Шаг 5: Запуск бота

```bash
cd src
python main.py
```

Если всё настроено правильно, в консоли появится:

```
Бот запущен!
Перейдите в Telegram: https://t.me/transport_ais_bot
```

### Шаг 6: Проверка работы

Откройте Telegram, найдите своего бота по username, отправьте `/start`. Бот должен ответить приветствием.

*Рис. 4 — Первый запуск бота и проверка команды /start*

## 3. Функциональные возможности бота

### 3.1. Главное меню с кнопками

```python
@bot.message_handler(commands=['start'])
def send_welcome(message):
    keyboard = types.ReplyKeyboardMarkup(resize_keyboard=True)
    keyboard.row("О проекте", "Пример работы")
    keyboard.row("Преимущества", "Калькулятор ROI")
    keyboard.row("Ссылки")
    
    bot.send_message(
        message.chat.id,
        "*Добро пожаловать!*\n\nВыберите раздел:",
        reply_markup=keyboard,
        parse_mode="Markdown"
    )
```

*Рис. 5 — Главное меню бота с кнопками*

### 3.2. Inline-кнопки (под сообщением)

В отличие от обычных кнопок меню, Inline-кнопки прикрепляются к конкретному сообщению:

```python
@bot.message_handler(func=lambda msg: msg.text == "О проекте")
def about_project(message):
    inline = types.InlineKeyboardMarkup()
    inline.add(types.InlineKeyboardButton("Технологии", callback_data="tech"))
    inline.add(types.InlineKeyboardButton("Экономика", callback_data="econ"))
    inline.add(types.InlineKeyboardButton("Сайт проекта", url="https://grehovadar51-star.github.io/project-practice"))
    
    bot.send_message(message.chat.id, "*О проекте*\n\n...", reply_markup=inline, parse_mode="Markdown")
```

Обработка нажатий на Inline-кнопки:

```python
@bot.callback_query_handler(func=lambda call: call.data == "tech")
def callback_tech(call):
    bot.edit_message_text(
        "*Стек технологий*\n\n...",
        call.message.chat.id,
        call.message.message_id,
        parse_mode="Markdown"
    )
```

*Рис. 6 — Inline-кнопки: навигация внутри одного сообщения*

### 3.3. Отправка изображений

```python
@bot.message_handler(func=lambda msg: msg.text == "Пример работы")
def example_work(message):
    caption = "*Пример работы системы*\n\nОператор загружает фото..."
    
    with open("interface.png", "rb") as photo:
        bot.send_photo(message.chat.id, photo, caption=caption, parse_mode="Markdown")
```

*Рис. 7 — Отправка фото с текстовой подписью*

### 3.4. Интерактивный калькулятор

Бот запрашивает данные у пользователя и производит расчёт:

```python
@bot.message_handler(func=lambda msg: msg.text == "Калькулятор ROI")
def calculator_start(message):
    bot.send_message(message.chat.id, "Введите количество грузов в месяц:")
    bot.register_next_step_handler(message, calculator_result)

def calculator_result(message):
    try:
        cargo_count = int(message.text)
        savings = cargo_count * 21
        bot.send_message(
            message.chat.id,
            f"*Результат*\n\n"
            f"Грузов в месяц: {cargo_count}\n"
            f"Экономия в месяц: *{savings:,} руб.*\n"
            f"Окупаемость: < 3 месяцев",
            parse_mode="Markdown"
        )
    except ValueError:
        bot.send_message(message.chat.id, "Введите число!")
```

*Рис. 8 — Калькулятор ROI: пользователь вводит данные, бот считает экономию*
