## Февраль 2026

### Формирование тестовой выборки грузов

Подготовлен набор изображений различных типов грузов для тестирования алгоритма. Выполнена разметка данных, определены эталонные значения объёмов для последующего сравнения.

## Март 2026

### Прогон алгоритма на всех типах грузов со сбором метрик

Алгоритм расчёта объёма протестирован на всём наборе изображений. Собраны метрики точности, скорости и стабильности детекции для каждого типа груза.

### Рефакторинг кода и настройка инфраструктуры

Монолитный скрипт `volume_test.py` разбит на модули: сегментация, геометрия, визуализация. Настройки вынесены из констант в `config.yaml`. Реализован запуск через аргументы командной строки (CLI).

### Начало работы над улучшением алгоритмов

Начата доработка функции расчёта объёма. Поставлена задача улучшить оценку высоты через 3D-проекцию. Алгоритм начал путаться в гипотезах ориентации паллеты (H1/H2) — требуется повышение надёжности выбора стороны.

## Март – Апрель 2026

### Ручной замер эталонных объёмов

Параллельно с прогоном алгоритма выполнены ручные замеры объёмов для формирования эталонной базы. Результаты зафиксированы и подготовлены к сравнению с расчётными данными.

### Разработка API и веб-интерфейса

Реализован REST API на FastAPI с эндпоинтом, принимающим изображение и возвращающим JSON с объёмом, габаритами и уверенностью. Разработан простейший веб-интерфейс: пользователь загружает фото, система возвращает изображение с рамками и плашками «Объём», «Статус».

### Пакетная обработка данных

Создан скрипт для прогона алгоритма по целой папке с фото и выгрузки итогового отчёта в CSV.

### Экономическое обоснование

Экономисты финализировали отчёт по аналогам. Проведён анализ конкурентов, сформированы требования к точности с точки зрения бизнеса. Подготовлен Pitch Deck с расчётом ROI.

---

## Апрель 2026

### Сравнение расчётных и эталонных значений

Проведён анализ отклонений между значениями, полученными алгоритмом, и данными ручных замеров. Определены основные источники погрешностей.

### Корректировка коэффициента meters_per_pixel

На основе анализа расхождений уточнён переводной коэффициент из пикселей в метры. Точность расчёта объёма повышена до целевого уровня более 95%.

### Сборка Docker-образа

Собран итоговый Docker-образ системы. Настройки прокидываются через переменные окружения и `config.yaml`. Подготовлен `docker-compose.yml`, запускающий всю систему одной командой. В README добавлена инструкция для заказчика по развёртыванию.

### Подготовка видеопрезентации

Записан скринкаст развёртывания системы с нуля: команда `docker-compose up`, запуск веб-интерфейса, загрузка тестового фото, демонстрация результата. В видео включены слайды от экономистов с расчётом окупаемости.
