# Участники проекта

## Команда разработки и интеграции

Команда отвечает за техническую реализацию системы: от детекции груза до упаковки в Docker-образ. В задачи команды входит разработка модулей сегментации и расчёта объёма, создание REST API на FastAPI, реализация веб-интерфейса для загрузки фото и отображения результатов, пакетная обработка данных с выгрузкой отчётов, контейнеризация приложения и подготовка инструкции для развёртывания у заказчика.

## Команда математики и алгоритмов

Команда отвечает за математическое обоснование метода расчёта объёма. В задачи команды входит разработка модели перевода пиксельных координат в метрические, описание 3D-проекции для устранения перспективных искажений, повышение точности оценки высоты груза и анализ надёжности выбора ориентации паллеты.
