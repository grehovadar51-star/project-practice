# Документация по выполнению практики

## Этапы работы

### 1. Настройка Git и репозитория
Создан репозиторий на GitHub, освоены базовые команды Git: clone, add, commit, push.

### 2. Написание документации в Markdown
Все материалы проекта оформлены в формате Markdown.

### 3. Создание статического веб-сайта
Сайт создан с использованием генератора Hugo. Реализованы страницы: Главная, О проекте, Участники, Журнал, Ресурсы.

### 4. Взаимодействие с организацией-партнёром
Проведены встречи с ООО «А+А ЭКСИСТ-ИНФО». Изучены бизнес-процессы транспортной компании.

### 5. Разработка Telegram-бота
Реализован бот на Python с использованием python-telegram-bot. Поддерживает 7 команд.

### 6. Подготовка отчёта
Отчёт оформлен в форматах DOCX и PDF.
