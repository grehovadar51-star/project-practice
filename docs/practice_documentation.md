## 1. Настройка Git и репозитория

На начальном этапе практики создан удалённый репозиторий на платформе GitHub. Освоены базовые команды Git: `clone`, `add`, `commit`, `push`. Настроена структура каталогов в соответствии с требованиями задания. Регулярно выполнялись коммиты с осмысленными сообщениями. Настроен файл `.gitignore` для исключения временных и служебных файлов.

## 2. Написание документации в Markdown

Все материалы проекта оформлены в формате Markdown. Подготовлены следующие документы:

- `project_description.md` — описание проекта: цель, задачи, проблематика, решение, технологии, экономика
- `architecture.md` — архитектура системы: компоненты, метод расчёта, API, схема обработки
- `team.md` — список участников с распределением по командам и ролями
- `journal.md` — журнал прогресса с хронологией выполнения задач
- `telegram-bot_guide.md` — техническое руководство по созданию Telegram-бота

## 3. Создание статического веб-сайта

Разработан статический веб-сайт на HTML и CSS. Сайт включает пять страниц: главная, о проекте, участники, журнал прогресса, ресурсы. Опубликован на платформе GitHub Pages. При создании использованы принципы адаптивной вёрстки, градиентное оформление, интерактивные элементы.

## 4. Взаимодействие с организацией-партнёром

Организовано взаимодействие с ООО «ЖелДорЭкспедиция» — крупнейшим транспортным оператором сборных грузов в России. Заказчик предоставил данные для формирования обучающей выборки и вычислительные ресурсы для обучения нейросетевой модели. Изучены бизнес-процессы компании и требования к системе определения объёма груза.

## 5. Разработка Telegram-бота

В рамках вариативной части практики разработан Telegram-бот на языке Python с использованием библиотеки pyTelegramBotAPI (telebot). Бот выполняет функцию витрины проекта и включает: главное меню с кнопками, информацию о проекте с Inline-навигацией, демонстрацию интерфейса системы, калькулятор окупаемости, внешние ссылки.

Подготовлено подробное техническое руководство по созданию бота в двух форматах:

- `telegram-bot_guide.md` — версия в Markdown, размещена в папке `docs/` репозитория
- отдельный документ в формате DOCX, размещён в папке `reports/`

## 6. Подготовка отчёта

Итоговый отчёт по проектной практике оформлен в форматах DOCX и PDF. Отчёт содержит: введение, общую информацию о проекте, характеристику организации-заказчика, описание выполненных работ по базовой и вариативной частям, достигнутые результаты, заключение и список литературы. Файлы отчёта размещены в папке `reports/`.
